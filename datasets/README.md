# Prototype datasets

## Katipunan walking network

- File: `katipunan-walking-network.osm`
- Source: OpenStreetMap map API
- Downloaded: 2026-10-15
- Bounding box: `121.065,14.635,121.083,14.650`
- License and attribution: OpenStreetMap contributors, Open Database License (ODbL)

The extract is limited to the ADMU and Katipunan prototype area. The backend filters the highway tags to construct a walking graph. It is not a complete citywide routing dataset.
