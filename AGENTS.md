# AGENTS.md

## Implementation and verification
* Perform tests after each major implementation step, rerun old tests to make sure that new implementation does not break old features already implemented
* Add or modify tests when required by the task or needed to verify new behaviour. Do not weaken or remove existing tests merely to make an implementation pass.
* Do not claim that a test or verification has passed unless you actually performed it.
* Report uncertainty when the available evidence is insufficient.

## Git and build log history
* Do not rewrite Git history, force-push, or erase commits.
* Preserve LOG.md content. Do not rewrite old content.
